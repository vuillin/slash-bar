# memo — Memo

Ouvre le panneau de raccourcis texte.

## Syntaxe

```
memo
```

## Comportement

| Action | Effet |
|--------|--------|
| `memo` | Ouvre / ferme le panneau latéral |
| Esc | Ferme le panneau |
| Onglet flèche | Replie / déplie |

Le contenu (liste de memos + `memo mail`, etc.) sera ajouté ensuite.

## Exemples

```
memo
```
