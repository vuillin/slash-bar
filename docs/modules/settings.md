# settings — Settings

App preferences panel.

## Syntax

```
settings          → toggle the panel
```

## Panel

Weather (default city, °C/°F, sunrise/sunset), hotkeys (read-only), and display theme.
Preferences persist in `%LocalAppData%\SlashBar\settings.json`.

Also opens from the gear icon to the right of `esc` on the bar.

## Examples

```
settings
```
