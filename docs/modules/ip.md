# ip — IP address

Copy an IP address to the clipboard.

## Syntax

```
ip           → public IP
ip local     → local IP (LAN)
```

## Options

| Option | Description |
|--------|-------------|
| _(none)_ | Public IP address (`api.ipify.org`) |
| `local` | Local IP address (LAN) |

## Examples

```
ip
ip local
```
