# calc — Calculatrice

Évalue une expression et copie le résultat.

## Syntaxe

```
calc <expression>
```

Opérateurs : `+` `-` `*` `/` et parenthèses. Espaces optionnels.

Accepté aussi : `×` `÷` `−`, virgule décimale (`2,5` → `2.5`).

## Exemples

```
calc 2+2
calc 2 + 2
calc (10 - 3) * 2
calc 3,14 * 2
calc 10 ÷ 4
```
