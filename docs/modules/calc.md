# calc — Calculator

Evaluate an expression and copy the result.

## Syntax

```
calc <expression>
```

Operators: `+` `-` `*` `/` and parentheses. Spaces are optional.

Also accepted: `×` `÷` `−`, decimal comma (`2,5` → `2.5`).

## Examples

```
calc 2+2
calc 2 + 2
calc (10 - 3) * 2
calc 3,14 * 2
calc 10 ÷ 4
```
